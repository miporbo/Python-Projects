# 📊 Grade Calculator

A simple Python CLI program that calculates a student's average marks 
from 3 subjects and determines their grade.

## Features
- Takes subject names and marks as input
- Calculates average automatically
- Displays grade based on average (A+ to F)

## How to Run

python Grade-Calculator.py

## Sample Output

Enter your name: Majharul
enter subject 1 name: Math
Math marks: 85
enter subject 2 name: Physics
Physics marks: 78
enter subject 3 name: English
English marks: 90
total average: 84.33
your grade is A+

## Tech Used
- Python 3
- Core concepts: input/output, conditionals (if/elif/else), f-strings
