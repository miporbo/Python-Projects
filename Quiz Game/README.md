# Quiz Game

A simple Python CLI quiz game that asks 5 questions one by one,
checks each answer, and shows the final score.

## Features
- Asks 5 questions stored as a list of dictionaries
- Ignores extra spaces and capital/small letter differences in answers
- Shows the correct answer when the player is wrong
- Displays the final score with a message based on performance
- Lets the player play again (yes/no)

## How to Run

python quiz_game.py
